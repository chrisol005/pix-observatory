3 · Roadmap — 4 semanas

Semana 1 Snowflake foundation + landing

Meta: dados brutos no Snowflake, plataforma configurada.

  • Conta trial · DBs DEV/PROD · warehouse XS · RBAC · resource monitor
  • S3 raw · storage integration · external stage · Snowpipe → schema RAW

Entregável: SELECT count(*) FROM raw.bacen_pix retorna linhas via Snowpipe.

Semana 2 dbt foundation: sources → staging → intermediate

Meta: camadas base verdes em dbt build, docs navegáveis.

  • dbt init · profiles dev/ci · packages (dbt_utils, dbt_expectations, codegen)
  • sources.yml + freshness · staging (views) · intermediate (ephemeral) · 1º macro
  • testes genéricos · dbt docs generate/serve

Entregável: dbt build --target dev verde + lineage no dbt docs.

Semana 3 Marts Kimball (star schema)

Meta: star schema completo, incremental, com SCD2 nativo.

  • dim_tempo (seed) · dim_instituicao (snapshot SCD2) · demais dims
  • fct_transacao_pix incremental (merge) · testes de relationships · exposure

Entregável: lineage fato→dims + diagrama do star schema no README.

Semana 4 Qualidade, CI/CD, docs, storytelling

Meta: pipeline auto-defendido, docs públicos, portfólio apresentável.

  • dbt_expectations + testes customizados (continuidade temporal, conservação de massa, valor>0)
  • CI: dbt build --target ci em zero-copy clone · slim CI (--defer --state)
  • dbt docs no GitHub Pages · Streamlit leve · README "hero" · candidatar a 5 vagas

Entregável: CI barra PR quebrado; dbt docs público; link do dashboard.
